*If the project is created in local (EclipseIDE) and it is yet to be linked with gitHub follow these steps*

1. Open gitHub > create repository > name as per Local project name > copy repository URL
2. Open project folder
3. Open gitBash here
4. Type:  `git init`
5.  It creates a .git folder , if not visible -> options  > show hidden files-> it confirms git init
6. Close and Open new GitBashHere
7. Type the following syntax
8.   `git add .`
    `git commit -m "Initial commit message"`
    `git remote add origin https://github.com/username/repo-name.git` ->repo URL
    `git push -u origin master'
9.  Cross chech whether the projects are updated in GitHub
